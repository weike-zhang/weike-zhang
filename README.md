## Projects

**dsh-svg-motion** — a DeepSeek Harness plugin that turns any SVG logo into a motion video. The model calls an `animate_svg` tool; the plugin renders a transparent 30fps assembly animation and synthesizes an MP4. Built from a real need: giving text-only agents a way to produce usable video assets.

**grounded-ai-tutor** — an Agent Skill that explains the missing step in plain language, assuming no technical background. Covers computer science, software, web, data, cloud and AI. Written to teach the way I'd want to be taught.

**project-publisher** — an Agent Skill that audits a GitHub project before launch: reviews the README, release notes and public files, then updates only what you approve. Builds release materials from what the project actually is, not a template.
